# Phase 2: Ilia Pulse map cartography

Implemented from Phase 1 commit `de487a9`. This phase changes the public map's
underlying cartography only. Phase 1 controls, markers, selected states, discovery
sheet, bundled worker and map lifecycle are preserved. No Phase 3 marker system,
regional architecture or temporal atmosphere is introduced.

## A. Provider and style architecture

| Concern           | Verified implementation                                                                                                                               |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| Public SDK        | MapLibre GL JS 6.10.0; direct integration in `SocialMap.tsx`                                                                                          |
| Runtime style     | Remote OpenFreeMap Bright JSON: `https://tiles.openfreemap.org/styles/bright`; fetched with an abort signal before constructing the map               |
| Vector source     | `openmaptiles`, TileJSON `https://tiles.openfreemap.org/planet`; current source zooms 0–14, overzoomed by the app up to zoom 18                       |
| Style assets      | Remote OpenFreeMap sprites and `{fontstack}/{range}.pbf` glyphs; retained without changes                                                             |
| Layers            | 119 upstream layers; 116 after the existing removal of administrative boundaries                                                                      |
| Customization     | Typed local transformation of known layer IDs/types, paint, layout, filters and zoom thresholds; remote data remains the source                       |
| Roads             | Highway, tunnel and bridge layers with class filters, widths, casings and ordering; rail, ferry, pier and aeroway layers                              |
| Land/water/nature | Background and vector landuse, landcover, park, water and waterway layers                                                                             |
| Terrain           | No DEM/elevation source, contours or active relief layer in this style. `ne2_shaded` is a declared low-zoom raster source but no Bright layer uses it |
| Coastline         | Water polygons provide the land/sea edge; no dedicated coastline stroke layer                                                                         |
| Text              | Provider settlement classes/ranks and Greek/Latin name expressions; Noto Sans Regular/Bold. Both Greek glyph ranges 768–1023 returned HTTP 200        |
| Visibility        | Existing zoom, rank and collision rules retained except the explicit density changes below                                                            |
| Themes/reload     | Single map initialization; no runtime `setStyle`. Palette tokens accept later variants, but no clock, theme switching or atmosphere is implemented    |
| Other map         | Admin Leaflet/OSM raster map is unchanged                                                                                                             |

The renderer supports per-layer style changes, but a full style replacement can
remove app overlays and would require reinstallation. Phase 6 should update
relevant paint properties against the existing instance; it must deliberately
handle text halos and any future opacity changes. Do not infer elevation or
custom font hosting from the capabilities of MapLibre alone.

References: [OpenFreeMap customization](https://openfreemap.org/quick_start/),
[MapLibre Map API](https://maplibre.org/maplibre-gl-js/docs/API/classes/Map/),
[MapLibre style specification](https://maplibre.org/maplibre-style-spec/).

## B. Changes made

The day palette uses warm ivory land `#f6f0e6`, Mediterranean blue water
`#a8c5ce`, charcoal primary labels `#302e2a`, warm-gray secondary labels
`#68645b` and muted water text `#425c68`. Nature uses soft green `#d9dfcd`
and olive `#879570`. Urban and building fills are warm neutrals with subdued
opacity/edges. Minor roads use cream with quiet warm casings; secondary roads
use sand; major roads use restrained ochre `#e3c69f` with `#b99c7b` casings.
Widths, dashes and road topology are preserved. Paths retain visible muted
casings rather than disappearing into the ivory land.

City and town labels gain available Noto Sans Bold and a measured size hierarchy.
Village labels remain regular and readable. Neighborhood/other labels begin at
zoom 13. Provider text, settlement ranks and collision behavior remain intact;
there are no hardcoded town labels. Sampled source data classifies Pyrgos as a
city, Amaliada/Zacharo/Ancient Olympia as towns, and Katakolo/Kourouta as villages.
The provider supplies Kourouta as **Kouroutas / Κουρούτας** in sampled zoom-11+
data; this phase preserves that source name and availability.

Base POIs retain only hospitals, museums, castles/ruins, monuments and parks,
while preserving original rank bands and zoom thresholds. Transit labels retain
airports, bus stations and railway stations/halts, beginning at zoom 13. Actual
sampled railway features use class `railway`; their icon expression maps to the
existing `rail` sprite. Ordinary bus stops and commercial POI clutter are removed.
Major-road names remain; minor-road names begin at zoom 16, path names at 17.
Major-road shields begin at zoom 11 with spacing 450, retaining the provider's
network/reference predicates.

Coastline clarity comes from the warm land/blue sea contrast, without polygon
outlines or seams. The active `hp-sea-shimmer` layer, its GeoJSON source and
pattern installation effect are removed from the public map. Its separate
simplified shoreline and repeating waves were too prominent for functional
cartography. No replacement water texture is added: an almost invisible effect
would add geometry, texture and lifecycle work with little orientation value.
The unused geometry generator and legacy overlay CSS are left untouched.

The daytime canvas filter is explicitly reset to `none` in the later map-base stylesheet, overriding the inherited declaration in markers.css, so map tokens and the existing orange route
render directly. The loading surface uses `--hp-bg`. The dormant legacy night
filter remains for later atmosphere work. An OpenFreeMap link joins the existing
licence control; OpenMapTiles, OpenStreetMap and ORS/HeiGIT routing credits remain.
[OpenFreeMap attribution guidance](https://openfreemap.org/#attribution) confirms
its own credit is optional, while OSM and OpenMapTiles attribution is required.

## E. Provider limitations and remaining verification

The remote style/data can change independently. Unknown or differently typed
layer IDs are left unchanged and missing optional layers are tolerated. The
fixture validates the inspected schema; it cannot certify future upstream
changes automatically. No local fallback or style pinning is added.

Town prominence remains constrained by provider classes, ranks, tile availability
and collision placement. Greek fonts are available, but this phase does not add
or host custom fonts. Low-zoom shaded-relief and elevation terrain are not active
features of the current Bright style. No dedicated coastline line is invented.

Existing marker size and marker/label occlusion remain Phase 1 behavior. Actual
route requests during UI verification fell back to the existing dashed straight
line without ETA. Numbered stops, centering and fallback line rendering were
verified; successful API geometry/solid route rendering was not observed.
Synthetic geolocation success and denial were exercised locally; physical GPS,
iOS safe areas, device brightness and outdoor viewing remain manual checks.

## F. Performance and legibility

The transformer runs once per mounted map, before construction, and does not
mutate the upstream object. No hooks/dependencies, pan/zoom handlers, filter
behavior or map recreation logic are added. There is no runtime style reload.
Sources, fonts, sprites and layer order remain stable. Removing the wave effect
also removes its active image, source and draw layer.

Temporary instrumentation outside the repository observed one map instance
through zoom, overview, filter and location interactions. React development
StrictMode produced two initial fetch attempts (the first aborted by cleanup),
then no additional style fetches for those interactions. Instrumentation and
synthetic geolocation are not shipped. Panning and zooming remained responsive
in side-by-side browser inspection; no device frame-time benchmark is claimed.

A 1,000-iteration local Node microbenchmark measured approximately 0.178 ms per
Phase 2 transformation versus 0.052 ms for the previous boundary-only transform.
This is initialization work, not frame work. The production PulseApp chunk was
427.74 kB raw / 133.00 kB gzip versus the Phase 1 437.42 / 136.77 kB, chiefly from
removing the imported shoreline geometry. Existing large-chunk warnings remain.

Token contrasts on flat fills: primary text/land 11.95:1, secondary text/land
5.20:1, water text/water 3.90:1, land/sea 1.60:1. Water text does not meet the
4.5:1 threshold for normal-size WCAG AA text; this report does not claim universal
AA label contrast. Halo placement, terrain blending, road widths and real screen
brightness still need visual judgment. Selected app markers and orange fallback
routes were distinguishable in the tested views.
